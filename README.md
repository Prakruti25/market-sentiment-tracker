# 📈 Real-Time Market Sentiment Tracker

A live dashboard that pulls Reddit discussions about stocks, analyzes sentiment using NLP, 
and correlates sentiment shifts with real-time price movements to surface market signals.

## 🎯 What This Project Does
- Streams posts and comments from finance subreddits via the Reddit API
- Scores sentiment using VADER + a transformer-based model for nuance
- Pulls live price data from Yahoo Finance
- Stores everything in a SQLite database for historical analysis
- Visualizes sentiment vs. price in an interactive Streamlit dashboard

## 🛠️ Tech Stack
Python · PRAW · yfinance · VADER · HuggingFace Transformers · SQLAlchemy · Streamlit · Plotly
